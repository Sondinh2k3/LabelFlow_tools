# ADR 0005 — Road review and measured optimizations

M4 keeps `road_extent`, visible Cityscapes road, `traffic_exclusion`, `suspected_region`, candidate objects and human image events independent. It does not determine legal violations, generate labels from hard-negative tags, or require dense masks on every positive frame. The existing editor gains a road protocol/quick layer selector; a separate `features/review` workspace handles capture metadata, trip management, stored-prediction comparison and dataset review.

Backend modules: `domain/review.rs`, `services/review/{metadata,predictions,metrics,queue,export}.rs`, and `commands/m4.rs`. No new npm, Cargo, Python or model dependency is introduced. Existing M3 worker predictions are read through a normalized adapter; viewing them does not launch Python. Imported canonical prediction JSON can include semantic IDs, independent binary regions, candidate shapes and a separate event assessment. Source UUID/SHA/dimensions/profile/class references are checked, and native import is scoped to the selected image.

Prediction storage is separate from ground truth. M3 keys use `ai:<uuid>`; M4 import keys use `review:<uuid>`. Overlay modes are GT, prediction, both and disagreement. Accept is an explicit revision-checked transaction, reusing the document/operation-log save path. Existing semantic values are preserved except ignore 255; existing binary regions are unioned with explicitly accepted predictions, and existing human events are preserved. Approved or stale documents are rejected. Rejection only updates prediction review status. Neither accept nor reject implies an image is approved; accepted documents require human review again.

Trips own a stable `trip:<uuid>` split group. All frames of one source video inherit that video's trip; assigning a trip through a frame applies to the entire video, including frames extracted later. An independent video-trip revision prevents a stale capture form on another frame from undoing a newer trip assignment. Existing M2 free-form video-group changes reject trip-managed videos. Annotation saves resolve assigned trip groups authoritatively; an old editor buffer cannot split frames across groups. No trip-delete or bulk destructive operation is offered.

Review metadata has its own optimistic revision. Hard-negative/weather/light/occlusion tags are explicit, allowlisted metadata, not inferred events. Capture GPS is optional and validated as a latitude/longitude pair. Trip distance is optional, positive finite metadata. Changing only tags/GPS does not replace an existing split group. Forms require explicit save; closing/navigating away from unsaved forms requires deliberate discard confirmation, including native window close.

Comparisons cache only numeric summaries at a GT revision. The queue shows the latest stored prediction per image, and disagreement filtering excludes missing/stale cached comparisons. Analysis is explicit, cancellable, and recorded in the existing jobs log; committed comparisons remain valid after interruption. Raster overlays/labels are never stored in the cache. Dense GT absence is unscored; explicit all-zero region masks are negative examples. This distinction avoids treating unannotated positives as segmentation negatives.

Metrics exports group by immutable model ID/version/SHA and choose the latest prediction per image within that group, preventing duplicate inference from inflating accuracy. Rejected predictions are still evaluated: dropping bad predictions from metrics would bias results. Only approved human labels count in aggregate metrics. Semantic ignore 255 is excluded; predicted ignore on labeled GT is an error. Region metrics use foreground IoU. Candidate object counts are displayed, but detection AP is not claimed. Event recall/precision use positive/negative only; uncertain/missing/draft rows remain in the export with explicit exclusion counts.

False-positive reviewed frames per supplied trip km is labeled separately. A static/sampled-frame dataset does not establish continuous event coverage or trigger episodes, so `falseTriggerEpisodesPerKm` stays null. No complete road-event performance claim is inferred from segmentation IoU. Exports contain metrics JSON/CSV, exact per-prediction JSON, separate human-document/metadata snapshots and checksums in a new directory, published only after verification. Prediction JSON reimports losslessly; human snapshots are read-only audit artifacts, while full project backup/restore is the supported GT restoration path.

Two localized optimizations are measured against M3 behavior: summary columns plus a covering index avoid reading large prediction JSON for suggestion lists, and Canvas2D raster rendering reuses same-size buffers and uses a native-endian 32-bit RGBA lookup. Exact output tests protect bytes, transparency and dirty bounds. Benchmarks report p50/p95 for these operations, not whole-app FPS/startup/RAM. No WebGL, propagation, tracking, dataset snapshots or other M5 workflow is introduced.
