# 0002 — M1 manual annotation engine

Accepted 2026-11-07. Extends ADR 0001; stops before M2. No cloud, API server, telemetry, video dependency or AI runtime.

- React owns workspace orchestration and accessible controls. `geometry` is pure TypeScript. `tools/EditorController` owns pointer interactions; `canvas/SceneRenderer` draws vectors, raster overlays, selection handles and temporary previews. Canvas uses canonical image coordinates; CSS/DPR transforms stay in the viewport. Raster edits update only dirty pixel rectangles during a stroke.
- `history/EditSession` owns immutable documents and ordered undoable commands. One completed stroke is one command. History is per image edit session, bounded to 100 commands or 64 MiB of distinct raster buffers; shared immutable masks count once. Navigation/relaunch resets undo history, while saved labels remain intact.
- A completed command is staged immediately in strict-durability IndexedDB before Rust IPC. Commands save immediately through a serial queue rather than waiting for a debounce; this narrows the recovery window. Every command carries an operation UUID and expected revision. Retries reuse both. Rust checks payload SHA and makes acknowledgment retries idempotent. `Saved` appears only after SQLite acknowledgment and journal removal. Pending saves are bounded; errors lock further edits and block navigation until explicit retry. An unfinished pointer stroke/polygon is a draft, cancellable with Escape, not yet a durable command.
- The project UUID **and root path** scope the local outbox, so restoring a backup into a different folder cannot replay the original project's pending operations. Startup replays the outbox before restoring the active image. Losing the WebView profile also loses pending outbox entries; acknowledged records remain authoritative in the project DB.
- SQLite schema 2 stores classes, layers, document revisions, events, normalized annotations and an operation log. A transaction commits all related records together. Document state references immutable, content-addressed grayscale PNG mask assets. Files are staged, synced and renamed before committing references; interrupted saves may leave orphan files, never committed references to unpublished files. Reopen inspection reports missing/corrupt assets and preserves orphan files for recovery.
- Semantic masks use Cityscapes **train IDs** 0–18, ignore 255. Road Extent, traffic exclusion and suspected regions use separate 0/1 rasters and/or region polygons. Export unions each region's raster with its own polygons minus holes; it never infers semantic classes from layer stacking. Raster visual compositing is deterministic profile order with adjustable opacity; ignore pixels are transparent only in the editor.
- Road profile configuration lives in `services/profile.rs`, not in geometry, history or the renderer. Generic M0 projects retain `generic-v1`. IDs never depend on palette positions. Class search and per-profile last-used class/layer settings persist locally. Built-in class creation/removal is not exposed in M1.
- Rust `commands` validates IPC and delegates to services outside the UI thread. `import` and `export` contain format implementations; `services/interchange` is a small typed facade. `services/backup` handles DB + masks. `jobs` persists job status/progress; an interrupted import can resume through reimport/deduplication, whereas an interrupted export restarts into a new output directory. No automatic background resume without a deliberate action.
- File/folder choices come from native dialogs or native drag/drop events. Drop paths are consumed from a backend allowlist, not trusted from arbitrary frontend strings. Imports reject links/reparse points, skip corrupt media with an itemized report and offer linked or managed copies. Changed linked content is rejected to preserve label identity. Thumbnail cache is rebuildable; only a page of 40 records is rendered.
- YOLO detection and semantic/region PNG are separate export paths. YOLO polygons/COCO/video are deferred to M2. Basic detection import matches UUID or unambiguous source stem and requires explicit class mapping; it does not parse arbitrary YAML configurations. RGB visualization masks are rejected. 8-bit indexed mask imports preserve palette indices, never convert colors into train IDs.
- New export directories are verified before rename; existing exports are never overwritten. Canonical PNG images accompany masks so EXIF rotations align. Grouped seeded splits preserve source-folder/trip groups; small group counts can yield empty splits, which the report warns about.
- No general filesystem, SQL, shell or network capability is granted to React. Explicit commands plus minimal event/window permissions suffice. The debug desktop smoke config alone enables loopback CDP; production does not.

Deferred optimizations: scoped binary previews instead of base64 PNG IPC, adjacent-image preloading, compressed/tile undo history and larger-library benchmarks. Their performance is not implied by the M1 functional tests.
