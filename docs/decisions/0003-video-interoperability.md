# ADR 0003 — Local video and dataset interoperability

Status: implemented for M2, 2026-11-07. M3 remains unimplemented.

- Video code lives in `src-tauri/src/video`; bounded subprocess handling, tool discovery and probe/decode are separate. Rust passes argument arrays directly, with no shell. File/pipe protocols only, no network protocols. Source files remain read-only. User-installed FFmpeg/FFprobe can be discovered on PATH, explicitly selected or supplied by test environment variables; neither binary is shipped in the app.
- FFprobe indexes presentation-order integer PTS, time base and frame duration in SQLite. VFR never uses frame-number/FPS arithmetic. Seek selects the nearest indexed PTS, with lower frame index as deterministic tie-breaker. Exact PNG/JPEG preview and extraction decode the selected presentation-order frame. Correctness takes priority over keyframe seeking in this baseline; decoding a distant frame from the beginning is a documented latency limitation.
- Source SHA-256 is verified before indexing, extraction and preview. Extraction also checks source modification metadata before publishing a frame. Immutable frame files are published before their SQLite reference. Cancellation preserves committed frames; reimport/extraction deduplicates by source video/frame index. Unreferenced frame files from an interrupted write may remain, never replace annotations, and can be adopted by a repeat extraction if identical.
- Schema 3 has separate `videos` and `video_frames` tables. It rebuilds `media` to correct the schema-2 placeholder FK to `videos`, then rebuilds `annotations` to allow multi-component polygons and instance masks. Migrations back up the previous SQLite DB, run transactionally with FK verification, restore FK enforcement and preserve original masks, documents and operation logs. There is no supported schema downgrade.
- A video owns the effective split group for all frames. Saving a frame cannot override this group. Multiple videos can share a trip group. Export deterministically hashes whole groups using the existing seed; it warns about empty partitions and persists split membership with the published manifest. Ratios are targets, not per-image quotas.
- Canonical instance geometry supports exterior/holes, disconnected components, and lossless full-image binary masks with crowd state. Instance mask pixels are stored in immutable content-addressed PNG assets, with references in documents and normalized rows, independently of semantic/region rasters. The editor displays and hit-tests imported instance masks; class reassignment/deletion are supported, pixel editing is deferred.
- YOLO segmentation accepts a single simple polygon without holes. Bboxes, disconnected components, holes and RLE are refused by default; explicit skip override records itemized warnings. There is no implicit contour approximation, polygon-to-box conversion or semantic relabeling. COCO exports polygon arrays where representable and compressed column-major RLE for holes/binary masks. COCO crowd annotations require RLE in this canonical baseline.
- Imports map every source category explicitly to stable project classes and match only already imported images, by UUID or unique basename and canonical dimensions. Ambiguous references are rejected, arbitrary COCO file paths are never opened. Deterministic imported annotation IDs make repeated identical imports idempotent. Approved documents are preserved. The import preview is tied to project root and consumed once.
- A bounded opaque-token `lfmedia` protocol serves registered preview/video resources. Windows WebView uses its internal `http://lfmedia.localhost` alias; this is not a localhost server and opens no listener. No arbitrary path is accepted by the handler. Video byte ranges are bounded to 8 MiB and full image responses to 128 MiB. Closing the project revokes the registry. The UI has no general filesystem, SQL or shell permission.
- Canonical PNG image previews and exact frame previews have checksum-verified, discardable disk caches with 256 MiB quotas per kind. Adjacent images/frames preload through native commands; they never change active media or documents. History counts unique instance-mask run arrays as well as raster buffers against its memory budget.
- Export preview/deep QA, review/event/group/annotation filters, and exact-content image/video path repair are exposed through typed IPC. Native jobs stay outside the UI thread. Modal focus suppresses annotation shortcuts. Playback depends on system WebView codecs; exact-frame FFmpeg decoding is the fallback.

Validation uses generated video fixtures, existing M1 fixtures, a 10k synthetic file import, packaged native smoke tests and external parsers. Python/Pillow/pycocotools and downloaded Ultralytics parser AST are test-only; no model, inference runtime or third-party parser source is embedded in LabelFlow. Parser acceptance is not a full training run.

Primary references inspected: [FFprobe](https://raw.githubusercontent.com/FFmpeg/FFmpeg/master/doc/ffprobe.texi), [FFmpeg](https://raw.githubusercontent.com/FFmpeg/FFmpeg/master/doc/ffmpeg.texi), [COCO RLE implementation](https://raw.githubusercontent.com/cocodataset/cocoapi/master/common/maskApi.c), [official Ultralytics parser at pinned commit](https://raw.githubusercontent.com/ultralytics/ultralytics/3cd02542899c1bcab5690b02033bc18aa07df0d4/ultralytics/data/utils.py).

Development machine FFmpeg comes from the [Gyan Windows build provider](https://www.gyan.dev/ffmpeg/builds/), verified against its published archive SHA-256 and kept in ignored `.tools/ffmpeg`. Redistribution was avoided. The AGPL Ultralytics source remains only in ignored validation cache; its unchanged selected parser functions run from AST for tests, not product runtime. No new npm or Cargo runtime dependency was added for M2.
