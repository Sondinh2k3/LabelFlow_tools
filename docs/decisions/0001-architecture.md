# 0001 — M0 architecture

Status: accepted for M0, 2026-11-06. Scope follows `LABELFLOW_CODEX_MASTER_PLAN.md` in full; implementation stops before M1.

- Tauri 2 hosts a React / strict TypeScript / Vite application. Tailwind is integrated through its Vite plugin; the small desktop shell uses named CSS classes. Component state is enough for M0; no additional state framework.
- `src/app` owns the shell, English string catalog and command map. `features/projects` and `features/media` expose typed services. `features/annotations/geometry` contains pure CSS-pixel transforms, independent of Canvas2D and React. `canvas` draws the original bitmap; future overlays will be separate renderer passes rather than per-pixel React elements.
- `src/lib/contracts` defines the explicit camelCase IPC contract. Rust `domain` serializes matching DTOs and typed error codes. Only five allowlisted commands are available to the local main window. No frontend filesystem, SQL, shell, network, or generic path-reading command.
- Native file/folder selection lives in Rust (`rfd`); source paths therefore come from a deliberate native selection, or from an already opened project's recorded reference. All blocking dialogs, file reads, decode and SQLite work run through `spawn_blocking`, serialized by the project session mutex. This bounds concurrent image decode to one. A failed or cancelled selection preserves the current project/image.
- `services` orchestrate workflows, `repositories` own queries, `database` owns connection setup and migration, `security` owns metadata path checks and the process lock. Original files are opened read-only. Metadata symlinks/reparse points are rejected. Root directories may be user-selected canonical locations; SQLite is local-disk only in M0.
- `.labelflow/project.sqlite` is authoritative. `project.json` identifies the portable project and must agree with the DB. SQLite enables foreign keys, WAL, FULL synchronous mode, version checks and quick integrity checks. Migration SQL and `user_version` commit in one transaction. Existing nonempty schemas are backed up through SQLite's online backup API before migration; a failed migration rolls back. M0 creates only the tables it uses: `projects`, `media`, `workspace`. Remaining conceptual tables arrive alongside their M1 features.
- An OS file lock is held for the entire connection lifetime. A competing writer is rejected. The persistent lock file is never unlinked; its existence alone does not indicate a live lock. OS release after process death makes reopening safe without a stale PID override.
- Image previews support JPEG/PNG/WebP, up to 64 MiB compressed and 24 million source pixels, decoder allocation limit 128 MiB. Rust applies EXIF orientation, records the original orientation and canonical dimensions, and returns a lossless PNG preview. The source SHA-256 detects changes at reopen. Base64 IPC is a bounded M0 spike; a scoped binary resource/cache should replace it before large-dataset work. No memory/performance target is claimed.
- Linked media is the M0 default and only mode. Store paths relative to the root when possible. The last selected image is restored on project reopen; missing or changed files produce visible errors while the project remains usable. Managed copies, directory import and remapping belong to M1/M2.
- The profile is `generic-v1` in M0; the Road Encroachment profile and its independent semantic/region/event semantics are implemented in M1. No annotation, export, autosave-edit journal, video, cloud or AI feature is partially exposed.
- The `1` shortcut temporarily means 100% zoom in M0. M1 must reserve `1..9` for class assignment and move actual-size zoom to a non-conflicting binding. `0` fits the image; wheel zooms to pointer; left/middle or Space-drag pans. Text-editing focus suppresses shortcuts.

Official references consulted: [Tauri prerequisites](https://v2.tauri.app/start/prerequisites/), [capabilities](https://v2.tauri.app/security/capabilities/), [Rust command IPC](https://v2.tauri.app/develop/calling-rust/). Installed crate sources are the API reference used for the exact locked Rust versions.
